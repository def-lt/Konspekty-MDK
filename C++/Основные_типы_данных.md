# Основные типы данных в C++ (конспект)

## 1. Классификация типов данных
В C++ типы данных делятся на:
- **Фундаментальные** (базовые, встроенные)
- **Составные** (массивы, структуры, классы, указатели и т.д.)

Ниже — только **фундаментальные типы**.

## 2. Целочисленные типы (`integer types`)

| Тип              | Размер (обычно) | Диапазон (примерно)                  | Примечание                  |
|------------------|-----------------|--------------------------------------|----------------------------|
| `char`           | 1 байт          | −128…127 или 0…255                   | Может быть signed/unsigned |
| `short` (`short int`) | 2 байта     | −32 768…32 767                       |                            |
| `int`            | 4 байта         | −2 147 483 648…2 147 483 647         | Основной целочисленный тип |
| `long` (`long int`) | 4 или 8 байт | Зависит от платформы                 | На 64-битных системах часто 8 |
| `long long`      | 8 байт          | ≈ −9·10¹⁸ … 9·10¹⁸                   |                            |

**Модификаторы:**
- `signed` — со знаком (по умолчанию для `int`, `short`, `long`)
- `unsigned` — без знака (только неотрицательные числа)

Примеры:
```cpp
int a = -10;
unsigned int b = 20;
short c = 100;
long long d = 10000000000LL;
```

## 3. Вещественные типы (с плавающей точкой)

| Тип           | Размер (обычно) | Точность                  | Пример                  |
|---------------|-----------------|---------------------------|-------------------------|
| `float`       | 4 байта         | ≈ 7 значащих цифр         | `3.14f`                 |
| `double`      | 8 байт          | ≈ 15–16 значащих цифр     | `3.1415926535`          |
| `long double` | 8, 10 или 16 байт | Выше, чем у `double`    | Зависит от компилятора  |

```cpp
float x = 3.14f;
double y = 2.718281828;
```

## 4. Символьный тип

- `char` — один символ (1 байт). Хранит код символа (ASCII/UTF-8).
- `wchar_t` — широкий символ (обычно 2 или 4 байта).
- `char16_t`, `char32_t` — для Unicode.

```cpp
char ch = 'A';
char str[] = "Hello";   // массив символов (строка в стиле C)
```

## 5. Логический тип

```cpp
bool flag = true;   // или false
```
Занимает обычно 1 байт. Значения: `true` (1) и `false` (0).

## 6. Тип `void`

- Обозначает отсутствие типа.
- Используется:
  - в функциях, которые ничего не возвращают: `void func();`
  - в указателях: `void* ptr;` (указатель на неизвестный тип)

## 7. Важные замечания

1. **Размер типов зависит от платформы и компилятора**.  
   Всегда лучше проверять через `sizeof`:
   ```cpp
   cout << sizeof(int) << endl;      // обычно 4
   cout << sizeof(double) << endl;   // обычно 8
   ```

2. **Литералы**:
   - Целые: `42`, `42U` (unsigned), `42L` (long), `42LL` (long long)
   - Вещественные: `3.14` (double), `3.14f` (float), `3.14L` (long double)
   - Символы: `'A'`, широкие: `L'A'`

3. **Автоматический вывод типа** (C++11 и новее):
   ```cpp
   auto x = 10;        // int
   auto y = 3.14;      // double
   auto z = true;      // bool
   ```

4. **Рекомендации**:
   - Для целых чисел по умолчанию используйте `int`.
   - Для вещественных — `double` (точнее, чем `float`).
   - Для размеров и индексов часто используют `size_t` (беззнаковый).
   - Избегайте `unsigned`, если нет особой необходимости (легко получить неожиданные результаты при вычитании).
